# 1190. Reverse Substrings Between Each Pair of Parentheses

## Problem Overview

You are given a string s that consists of lower case English letters and brackets. Reverse the strings in each pair of matching parentheses, starting from the innermost one.

## Examples

### Example 1

**Input:**
```text
s = "(abcd)"
```

**Output:**
```text
"dcba"
```

### Example 2

**Input:**
```text
s = "(u(love)i)"
```

**Output:**
```text
"iloveu"
```

**Explanation:**

The substring "love" is reversed first, then the whole string is reversed.

### Example 3

**Input:**
```text
s = "(ed(et(oc))el)"
```

**Output:**
```text
"leetcode"
```

**Explanation:**

First, we reverse the substring "oc", then "etco", and finally, the whole string.
