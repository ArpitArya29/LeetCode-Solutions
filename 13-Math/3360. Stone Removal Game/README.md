# 3360. Stone Removal Game

## Problem Overview

Alice and Bob are playing a game where they take turns removing stones from a pile, with Alice going first. The player who cannot make a move loses the game.

## Examples

### Example 1

**Input:**
```text
n = 12
```

**Output:**
```text
true
```

**Explanation:**

Alice removes 10 stones on her first turn, leaving 2 stones for Bob.

Bob cannot remove 9 stones, so Alice wins.

### Example 2

**Input:**
```text
n = 1
```

**Output:**
```text
false
```

**Explanation:**

Alice cannot remove 10 stones, so Alice loses.
