# 3963. Create Grid With Exactly One Path

## Problem Overview

You are given two integers m and n, representing the number of rows and columns of a grid. Construct any m x n grid consisting only of the characters '.' and '#', where:

## Examples

### Example 1

**Input:**
```text
m = 2, n = 3
```

**Output:**
```text
["..#","#.."]
```

**Explanation:**

The only valid path is: (0,0) &rarr; (0,1) &rarr; (1,1) &rarr; (1,2)

### Example 2

**Input:**
```text
m = 3, n = 3
```

**Output:**
```text
["..#","#..","##."]
```

**Explanation:**

The only valid path is: (0,0) &rarr; (0,1) &rarr; (1,1) &rarr; (1,2) &rarr; (2,2)

### Example 3

**Input:**
```text
m = 1, n = 4
```

**Output:**

```text
["...."]
```

**Explanation:**

The only valid path is: (0,0) &rarr; (0,1) &rarr; (0,2) &rarr; (0,3)
